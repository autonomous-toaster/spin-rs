## Task Reference

| Task ID | Description |
|---------|-------------|
| T7.1 | Generate Spin-compatible error trail files |
| T7.2 | Replay error trails from trail files |
| T7.3 | Report verification statistics |

## ADDED Requirements

### Requirement: Generate error trails

T7.1 SHALL produce Spin-compatible `.pml.trail` files when a property violation is detected. The trail format SHALL match Spin's binary trail format (sequence of state/transition records) consumable by `spin -t`. T7.1 SHALL complete AFTER the verification engine detects a violation.

#### Scenario: Safety violation trail

- **WHEN** T7.1 receives a violation trace of 5 states from the engine
- **THEN** T7.1 SHALL write a `.pml.trail` file that Spin's `spin -t` can replay

#### Scenario: Empty trail (no violation)

- **WHEN** verification completes with no errors
- **THEN** T7.1 SHALL not produce a trail file

### Requirement: Replay error trails

T7.2 SHALL read Spin trail files and replay the error sequence against the model, printing the state at each step. T7.2 SHALL support both spin-rs generated trails and Spin-generated trails. T7.2 SHALL complete AFTER T7.1 SHALL write the trail.

#### Scenario: Replay from Spin

- **WHEN** T7.2 receives a `.pml.trail` generated by Spin 6.5.x
- **THEN** T7.2 SHALL replay the exact same sequence of states and transitions

### Requirement: Report statistics

T7.3 SHALL report verification statistics in Spin-compatible text format: states explored, states stored, transitions, hash conflicts, depth reached, memory usage, and elapsed time. T7.3 SHALL complete AFTER verification finishes.

#### Scenario: Verification output

- **WHEN** T7.3 completes after exhaustive DFS
- **THEN** T7.3 SHALL print: `State-vector 28 byte, depth reached 15, errors: 0` and similar Spin-compatible stats
